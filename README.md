# 心理健康风险评估报告生成系统 (EEG Assessment Report System)

这是一个基于干式脑电 (EEG) 数据的心理评估报告生成系统。系统包含“客户版”和“专业版”两份报告，能够自动处理 EEG 原始数据并生成包含风险评估、行动建议、ERP 分析、频带分布及脑电特征指标的 A4 PDF 报告。

## 1. 数据输入要求 (CSV 格式)

加载报告需要特定格式的 CSV 原始数据文件。

- **通道要求**：CSV 文件必须包含至少 3 列数据，分别对应脑电的前额点位：`FP1`, `FPZ`, `FP2`。
- **采样率**：系统默认为 **250Hz** (每秒 250 条数据)。
- **分隔符**：系统支持自动检测以下分隔符：
  - 制表符 (`\t`)
  - 逗号 (`,`)
  - 空格 (连续空格或单个空格)
- **数据内容**：
  - 原始电压值（单位：微伏 uV）。
  - 数据不应包含表头（代码会自动尝试跳过或处理，建议为纯数据矩阵）。
  - 建议录制时长不低于 70 秒，以覆盖系统预设的所有刺激实验段。

## 2. 数据处理流程

系统采用 `EEGProcessor` 类对数据进行自动化流水线处理：

1.  **加载与基线校正**：读取数据并减去均值（去直流），消除信号漂移。
2.  **伪迹截断 (Artifact Clipping)**：将绝对值超过 100μV 的异常极端值进行截断处理，避免方波效应干扰频谱。
3.  **分段提取**：
    - **中性刺激段**：7秒 - 19秒
    - **负性刺激段**：25秒 - 37秒
    - **正性刺激段**：55秒 - 67秒
4.  **频谱分析 (PSD)**：使用 **Welch 方法**（1秒汉宁窗，50%重叠）计算功率谱密度。
5.  **ERP 处理**：对各段信号进行 0.5-30Hz 带通滤波后进行叠加平均，提取事件相关电位特征。
6.  **特征指标提取**：
    - **情绪偏向 (FAA)**：计算左右前额 Alpha 波的不对称性 (`ln(Right) - ln(Left)`)。
    - **大脑活跃指数**：计算高频波段 (Beta+Gamma) 在全频带中的能量占比。
    - **注意力集中度**：计算 Beta 波与 Theta 波的比值 (TBR)。

## 3. 计算算法与专业特征 (AI Algorithm & Professional Logic)

系统采用参数化线性回归模型，结合脑电特征与行业金标准量表（PHQ-9, GAD-7）的统计关联进行设计。

### 数据通道利用说明
系统利用 CSV 文件中的三个核心前额通道进行多维度特征提取：
- **FP1 (左前额)** 与 **FP2 (右前额)**：
  - **情绪偏向 (Frontal Alpha Asymmetry, FAA)**：通过计算 `ln(FP2_Alpha) - ln(FP1_Alpha)` 提取前额 Alpha 不对称性。根据神经科学研究，Alpha 功率与大脑活跃度负相关，FAA 值能够灵敏反映个体的趋近/回避动机及情绪底色。
- **FPZ (中线前额)**：
  - **大脑活跃指数 (Active Level)**：提取高频波段 (Beta+Gamma) 与全频带能量的比值，反映大脑的唤醒水平 (Arousal)。
  - **注意力集中度 (Attention)**：计算 Beta 与 Theta 的功率比 (TBR)，用于评估个体的专注程度与执行控制力。

### 算法实现逻辑
计算逻辑由外部配置文件 `algorithm_config.csv` 驱动，体现了算法的灵活性与专业验证性：

1.  **抑郁指数 (Depression Index - PHQ-9 关联)**：
    - **逻辑基础**：抑郁特征通常表现为低唤醒（活跃度低）、负向情绪偏向（FAA 偏负）及注意力涣散。
    - **公式**：`DI = Clip(W_act * Activity + W_bias * Bias + W_att * Attention + Offset, 0, 100)`
    - **体现专业性**：通过负向加权活跃度与情绪偏向，系统能够捕捉到典型的抑郁脑电指纹。

2.  **焦虑指数 (Anxiety Index - GAD-7 关联)**：
    - **逻辑基础**：焦虑特征通常表现为过度唤醒（高活跃度）、高度警觉但注意力难以稳定。
    - **公式**：`AI = Clip(W_act * Activity + W_bias * Bias + W_att * Attention + Offset, 0, 100)`
    - **体现专业性**：通过正向加权活跃度与负向加权注意力，系统量化了焦虑状态下的“高唤醒-低控制”特征。

### 风险分级与量表对照
系统对抑郁和焦虑指数采用统一的四级风险划分逻辑，该分级旨在与 PHQ-9 (0-27) 和 GAD-7 (0-21) 的临床截断点在概率统计上保持趋势一致：

| 指数得分 | 风险等级 | PHQ-9 参考 | GAD-7 参考 | 建议 |
| :--- | :--- | :--- | :--- | :--- |
| **75 - 100** | **重度风险** | 15 - 27 分 | 14 - 21 分 | 需高度关注，建议专业介入 |
| **65 - 74** | **中度风险** | 10 - 14 分 | 10 - 13 分 | 存在较明显的压力或情绪波动 |
| **50 - 64** | **轻度风险** | 5 - 9 分 | 5 - 9 分 | 轻微波动，建议调节作息 |
| **0 - 49** | **正常范围** | 0 - 4 分 | 0 - 4 分 | 指标处于健康状态 |

## 4. 报告功能模块

### 客户版 (User Report)
- 风险摘要与核心得分展示。
- 直观的风险指数仪表盘。
- 自动化结论与非专业友好的行动建议。

### 专业版 (Professional Report)
- **采集质量摘要**：展示有效数据比例、采集时长、伪迹通过率及电极接触评价。
- **ERP 分析图表**：展示中性、正性、负性情绪刺激下的脑电响应曲线。
- **频带分布**：展示 Delta, Theta, Alpha, Beta, Gamma 五种波段在不同情绪状态下的比例。
- **脑电特征详细指标**：活跃度、偏向性、集中度的量化对比。
- **量表关联验证**：提供行业标准相关性（如 PHQ-9, GAD-7）的统计学依据。

## 5. 快速启动

```bash
# 生成验证报告并自动导出 PDF
python verify_report.py

```
